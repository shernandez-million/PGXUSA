# PGX Builders Group

Sitio web estático bilingüe de PGX Builders Group, preparado para publicarse en Vercel.

## Estructura

- `index.html`: versión en inglés.
- `es.html`: versión en español, publicada en `/es` mediante URLs limpias.
- `images/`: imágenes del sitio.
- `sitemap.xml` y `robots.txt`: archivos para motores de búsqueda.

## Publicación

Vercel puede servir el repositorio directamente, sin comando de compilación ni directorio de salida. El dominio canónico configurado en el sitio es `https://www.pgxusa.com`.
